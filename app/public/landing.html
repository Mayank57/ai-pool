FAQ

Questions teams ask first

Is pooling subscriptions allowed by Anthropic and OpenAI?

Consumer plans (Claude Pro/Max, ChatGPT Plus/Pro) are licensed to one person, and sharing one person's plan with others can break the provider's terms. The safe pattern is private mode: each person connects their own company-paid plan and uses it themselves, while AI Pool handles keys, budgets and reporting. Business plans and API keys (as overflow) are the sanctioned routes for shared capacity. Check your plans' terms before sharing.

Where are our credentials stored?

On the machine running AI Pool. In this build that's your own computer or server; requests go only to Anthropic and OpenAI. Upstream API keys are encrypted at rest. Plan sign-ins are stored by the routing engine on the same machine.

What happens when every plan hits its limit?

Requests fail with a rate-limit error until a window resets, unless you added an overflow API key. Then AI Pool switches to it and bills per token at the provider's price.

Does anyone have to change tools?

No. Claude Code, Codex, OpenCode, Cursor and any OpenAI- or Anthropic-compatible client work by changing the base URL and key. The setup script does it for Claude Code and Codex.

Can admins read our prompts?

AI Pool's dashboards are built from metadata only: time, model, token counts, which key and plan, and latency. Prompt and response text isn't stored, except the routing engine keeps the last few failed requests on the server for debugging.
